# Aya's Bookstore 📚

A modern, responsive e-commerce web application for an online bookstore built with ReactJS for CSCI426 project.

## 🚀 Features
- **Home Page:** Welcoming hero section with custom branding.
- **Browse Books:** Dynamic book listings with price, author, and category filtering.
- **Features & About:** Detailed overview of store capabilities and background.
- **Contact:** Interactive contact form for user queries.

## 🛠️ Technologies Used
- **Frontend:** ReactJS, HTML5, CSS3 (Custom Modular CSS)
- **Routing:** React Router DOM
- **Version Control:** Git & GitHub
